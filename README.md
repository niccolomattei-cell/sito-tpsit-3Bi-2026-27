## Che cos'è

Il repository contiene il materiale del corso **TPSIT 2026/2027 della classe 3BI** di un sito che cresce a ogni modulo del corso. 

Il progetto nasce come esercitazione didattica.

## Come si consulta

Le pagine sono divise per modulo da M0 a M8 che corrispondono ad altrettante cartelle

[Per consultare](https://github.com/niccolomattei-cell/sito-tpsit-3Bi-2026-27)

## Come si lavora sulla propria copia

Sulla postazione del laboratorio, dopo aver aperto il prompt dei comandi:

```bash
git clone https://github.com/niccolomattei-cell/sito-tpsit-3Bi-2026-27
cd sito-tpsit-3Bi-2026-27
code .
```

## Come è organizzato

| Elemento | Tipo | Descrizione / Contenuto |
| :--- | :--- | :--- |
| **`sito-tpsit-3Bi-20...`** | Cartella principale | Directory radice del progetto |
| **`appunti lezione`** | Cartella | Raccoglitore degli appunti delle lezioni |
| **`Esercizi`** | Cartella | Raccolta generale degli esercizi |
| **`M0`** | Cartella | Materiali relativi al Modulo 0 |
| **`M1`** | Cartella | Materiali relativi al Modulo 1 |
| **`M1_es\appunti`** | Cartella | Sottocartella con appunti ed esercizi del Modulo 1 |
| **`.gitignore`** | File di configurazione | Elenco dei file e delle cartelle da ignorare in Git |
| **`README.md`** | File Markdown | Documento descrittivo principale del repository |
